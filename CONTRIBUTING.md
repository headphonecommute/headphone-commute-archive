# Contributing

This archive is a faithful copy of Headphone Commute's published writing. It is not edited or updated by readers, and the text of articles is not corrected, modernised or rewritten.

**Please open an issue** if you find:
- a file that does not open, has broken formatting, or is missing text compared with the original article;
- a broken link between two archived articles;
- a problem with the website, the catalogue, or the checksums;
- a mirror or copy you would like listed.

Changes to the archive files are made by the publisher, through the same process that produced them, so that every copy stays verifiable. Pull requests that edit article text will not be merged.

To check your own copy before reporting a problem, run `sha256sum -c SHA256SUMS` and `python3 -m pytest tests`.
